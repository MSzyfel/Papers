\chapter{Experimental Results}

This chapter presents comprehensive experimental evaluation of the algorithms discussed in the theoretical analysis. The experiments are organized following the same structure as the theoretical chapter, with sections corresponding to different problem variants. For each algorithm and graph class, we provide detailed results based on various probability distributions and instance sizes.

The experimental methodology involves generating random instances using the \texttt{Tree} class implementation, applying the algorithms, and measuring their performance metrics. Results are presented in tabular form, derived from CSV data files containing the experimental measurements.
