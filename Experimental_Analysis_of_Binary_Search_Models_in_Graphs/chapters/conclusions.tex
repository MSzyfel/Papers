\chapter{Summary}

This thesis presented an experimental analysis of the worst-case Graph Search Problem in tree graphs. We explored various algorithms designed to tackle the Tree Search Problem with both uniform and non-uniform query costs. The main results of this work is that the computational experiments confirm the therethical claims regarding both the approximation ratios achieved by the presented algorithms as well as their running times. We also showed new theorethical results for the problem including a redisgned QPTAS for the non-uniform query cost model as well as an $O\br{\log \log n}$-approximation algorithm runnning in parametrized time. Moreover, we introduced three field notation enabling unified and sparse way of denoting various Graph Search Problem variants.

For the case of the non-uniform cost model, the costs of the solutions built by all algorithms were relatively low, and no particular algorithm significantly outperformed the others. Importantly, none ever procuded an output of cost worse then $3\cdot\OPT$. This suggests that on random instances most heuristics perform well. However it should be noted that the least algorithmically complex procedure, i.~e. the $O\br{\log n/\log\log n}$-approximation algorithm usually achieved slightly better quality then the others. This counterintuitive result suggests that on such instances, the most greedy-like algorithms perform best. This is visible in comparision to the $O\br{\log \log n}$ approximation algorithm achieving the worst approximation ratios which is probably due to the fact that it processes many cost levels and each such level incurses additional $O\br{\OPT}$ cost. Therefore, despite its better asymptotic guarantee, it often performs slightly worse then the $O\br{\log n/\log\log n}$ and $O\br{\sqrt{\log n}}$-approximation algorithms.

The other important conclusion drawn from the experimental analysis is that the state-of-the-art approximation algorithms for the non-uniform query cost model are of practical use only for relatively small instances, up to several dozens of vertices. Beyond that, the $O\br{\log n/\log\log n}$-approximation algorithm is the only one with acceptable running time. Since all of the tested algorithms provided achieved similar quality of the solutions the $O\br{\log n/\log\log n}$-approximation algorithm is to be prefered for practical usage. The $O\br{\log\log n}$-approximation algorithm, while theoretically interesting, is impractical for real-world applications due to its high computational complexity. We observe that no particularly hard instances (in terms of approximation quality) were found during the execution of our experiments. This suggest that they might be very scarce. It would be therefore of interest to find such instances and conduct further studies evaluating the quality of the above procedures on them.

Another advantage of the $O\br{\log n/\log \log n}$-approximation algorithm is the stability of its running time. No sudden running time spikes were observed for the procedure. In contrast, both of the procedures based on the QPTAS exhibited significant variance in their running times, even on instances of the same size. This is due to the fact that whenever the QPTAS was called for a tree with large value of $\rank\br{T}$, the running time increased significantly. Note that this value can be large even for trees with very simple strictures, for example paths are the trees with the largest possible value of $\rank\br{T}$ equal to $\fl{\log\br{n}}+1$. Observing the behaviour of the algorihms manually we noticed that the auxiliary trees for which the QPTAS was called usually had a path-like structure, which significantly increased the running time of the algorithms. 


For the uniform query cost model we observe that the naive $O\br{n\log n}$ implementation of the linear time algorithm based on calculating the ranking coloring performed differently among the three considered classes of trees. On randomly generated and bounded degree instances the observed running times were almost linear while for the bounded diameter instances they matched the upper bound of $O\br{n\log n}$. On the other hand for the bounded diameter instances the depth of the decision tree was always at most $4$. For randomly generated and bounded degree instances the depth of the decision trees produced by the algorithm behaved logarithmically in $n$. While for bounded degree trees this is to be epectedt, for randomly generated instances this behavior of $\rank\br{T}$ is more suprising. We conjecture that given a random tree $T$ on $n$ vertices, $\rank\br{T}=\Theta\br{\log n}$. 

The bound $\rank\br{T}\leq \cl{\frac{\diam\br{T}+1}{2}}$ also shows that for trees with bounded diameter, the running time of the QPTAS for $T||V,c||\COST_{max}$ is in fact polynomial in $n$ and the algorithm becomes a PTAS running in $n^{O\br{\diam\br{T}/\epsilon^2}}$. It would be interesting to verify whether a similar result can be obtained for trees with bounded degree as well. Since for such trees the ranking is always of order $\Theta\br{\log n}$, a new technique would have to be designed. However, it is possible that other structural properties of such trees can be exploited to obtain constant factor approximation for such trees.

Another intersting observation is the suprisingly good performance of the $O\br{2^nn}$ time exact algorithm. Despite its exponential time complexity, it was able to solve instances with up to 33 vertices within reasonable time limits. By performing a generic regression of the running time of the algorithm we observe that its practical running tightly matched an exponential function with base $b\approx 1.34 $-$1.61$. Upon careful examination of the exact algorithm one may observe that in fact the upper bound on its running time is the number of connected subtrees of $T$. Since we generated our random trees using Prüfer sequences, by \cite{SubTsofRT} we know that the expected number of connected subtrees of a tree generated in this way is of order $O\br{1.4196^n}$ which matches the experimentally obtained values. Although this is still exponential, it is significantly better than the worst-case bound of $O\br{2^n}$. This suggests that the exact algorithm may be practical for small to medium-sized instances, especially when the input trees have certain structural properties that limit the number of connected subtrees. In recent years many NP-hard problems, such as the Traveling Salesman Problem or the Steiner Tree Problem, have seen significant improvements in their exact exponential time algorithms \cite{ExpTAlgs}. It is therefore an interesting research direction to investigate whether similar improvements can be obtained for the Tree Search Problem as well.

The non-uniform cost model enforces the use of complex algorithmic techniques, and non-polynomial time subroutines in order to achieve satisfying approximation guarantees. For practical usage this provides a two-fold challenge: on the one hand, it makes the algorithms hard to implement and debug, on the other hand, it limits their practical usability beyong small instances. Due to this, the experimental analysis conducted in this thesis required significant effort. This was particularly noticeable during the implementation of the QPTAS for $T||V, c||\COST_{max}$ both in terms of the used data structres with operations on them as well as the algorithm itself, consisiting of few cases of a complex dynamic programming procedure. It is interesting, whether it is possible to derive similar results, using simpler techniques. In particular, a further research direction would be to simplify the QPTAS both in terms of the large constant in the exponent and the algorithm itself. A central question in this line of research if whether is is possible to derive constant factor approximation guarantee for the non-uniform query cost model or ideally, a PTAS. As of right now, no inapproximability results are known for this problem, besides a trivial non-existence of an absolute approximation algorithm. Therefore, this problem is included among the specific list of problems for which an $O\br{\sqrt{\log n}}$-approximation is known, but there is no lower bound matching this result. A similar issue is prevalent among many separation problems such as treewidth, vertex separators and edge cuts \cite{ExpFsGEandGPart,PartGsintoBComps, Improvedapproximationalgorithmsvertexseparators} for which an $O\br{\sqrt{\log n}}$-approximation algorithms are known, but no lower bounds beyond constant factor inapproximability are known. Interestingly, these problems are connected to Tree Search Problem, since they can be used to derive relatively simple constant factor approximation algorithms for $T||V,c,w||\sum C_i$ and $T||E,c,w||\sum C_i$\cite{szyfelbein2025approximatingaveragecasegraphsearch,Acostfunctionforsimilaritybasedhierarchicalclustering,Approximatehierarchicalclusteringviasparsestcutandspreadingmetrics}.  

A future way to decrease the approximation ratio would be to devise a dynamic program which stores less information for each box of the boxed decision tree. As of right now each of $\rank\br{T}$ boxes require enumerating $O\br{n}$ values of load. Reducing this amount to $\text{poly}\br{\log n}$ would immediately yield a polynomial time algorithm with approximation ratio of $O\br{\log \log n}$. However, we think that this is a very challenging task, since the load values are crucial to ensure that the merging and rotating operations are performed correctly. A different way to achieve such approximation ratio would be to design an algorithm similar to the one used for the $k$-up modular cost function, recursively splitting the cost levels into $O\br{\log \log n}$ levels and processing each separately. However, it is not clear how to perform merging of such strategies in polynomial (or almost polynomial) time simultaneously ensuring that the cost incurred at each level is $O\br{\OPT}$.
