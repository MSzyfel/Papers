\textbf{Observations:}
\begin{itemize}
    \item Greedy algorithm consistently achieves near-optimal performance
    \item Approximation ratios typically below 1.5 in practice
    \item Very fast runtime, suitable for large instances
    \item Performance varies with weight distribution skewness
\end{itemize}
