\subsection{FPTAS Algorithm}
\label{sec:fptas}

Fully Polynomial-Time Approximation Scheme with runtime polynomial in both $n$ and $1/\epsilon$.

\textbf{Observations:}
\begin{itemize}
    \item FPTAS provides strong theoretical guarantees with polynomial runtime
    \item Runtime grows polynomially with decreasing $\epsilon$
    \item Achieves near-optimal solutions for small $\epsilon$ values
    \item More efficient than PTAS for fine approximations
\end{itemize}
