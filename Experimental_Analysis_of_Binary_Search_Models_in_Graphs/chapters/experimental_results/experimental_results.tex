\section{Overview of the experiments}
\label{sec:experiments_overview}

The experimental analysis is divided into two sections concerning uniform and non-uniform query costs. In the first section we measured the running time of the \FRankingBasedDT algorithm from Section~\ref{sec:trees_uniform_costs} and the depth of the decision trees produced by it. The second section was concerned with the non-uniform cost model and included the evaluation of the $O\br{\log n/\log\log n}$-approximation algorithm from Section~\ref{sec:log_n_log_log_n_approx}, the $O\br{\sqrt{\log n}}$-approximation algorithm from Section~\ref{sec:sqrt_log_n_approx} based on the QPTAS and the $O\br{\log\log n}$-approximation algorithm from Section~\ref{sec:log_log_n_approx}. We compared the quality of the solutions produced by these algorithms on various classes of trees and cost functions and the computation time required to obtain these results. Additionally, for small input sizes we managed to calculate the optimal solutions using the exact exponential time algorithm. This allowed us to compare the approximation ratios of the algorithms with respect to the optimal solutions.

We have also employed a few heuristic speed-ups, particularly for the QPTAS. Firstly, instead of using $\epsilon=1$ we set it to $\epsilon=59$, which reduces most of the computational complexity of each QPTAS call. For both the $O\br{\sqrt{\log n}}$-approximation algorithm and the $O\br{\log\log n}$-approximation algorithm this does not impact the asymptotic guarantee of the algorithms. Secondly, a careful reading of the analysis of the QPTAS reveals that the depth of the considered boxed decision trees can be limited to $\rank\br{T}$. This reduces the running time of the QPTAS to $n^{O\br{\log \rank\br{T}/\epsilon^2}}$, which in practice is usually slightly better than the upper bound $\rank\br{T}=O\br{\log n}$.

Lastly we decided to simplify the implementation of the linear time algorithm for $T||V||\COST_{max}$ based on calculating the ranking coloring. We implemented this algorithm niavely with $O\br{n\log n}$ time complexity. This is done in order to simplify the already complex implementation. Additionally, this running time is negligible compared to the other algorithms and we are mainly focused on the quality of the solutions produced by them. Also note that although we performed experiments for the uniform costs variant of the problem using this algorithm, the main focus of this thesis is the non-uniform costs model and this algorithm serves as an essential subroutine for both QPTAS and the $O\br{\log\log n}$-approximation algorithm, rather then a standalone procedure.

\subsection*{Tree Generation Methods}

We used three different methods of generating random trees for our experiments: random trees, random trees with bounded degree and random trees with bounded diameter. 
Table~\ref{tab:tree_methods} summarizes all tree generation methods used in our experiments. For the uniform costs model, we decided to measure the performance of our algorithms on instances of sizes 10 to 1000 with 10 instances per size. For non-uniform costs model, we focused on relatively small instances, 10 to 100 vertices per instance, since the complex dynamic programming subroutines of our algorithm require significant computation time even for such sizes.

\subsubsection*{Detailed Generation Algorithms}

\paragraph{Random Trees.} Generated using NetworkX's \texttt{random\_labeled\_tree} function, which employs Prüfer sequences to sample uniformly from all labeled trees on $n$ vertices. A random vertex is chosen as root, and the tree is oriented via BFS traversal from this root.

\paragraph{Random Bounded Degree Trees.} Constructed incrementally by maintaining a list of available parent nodes with fewer than $\Delta-1$ children. Each new vertex is attached to a uniformly random available parent. When a parent reaches its degree limit, it is removed from the available list. This ensures every vertex has total degree at most $\Delta$.

\paragraph{Random Bounded Diameter Trees.} For diameter bound $D$, vertices are distributed across $h = \lfloor D/2 \rfloor + 1$ levels. The root occupies level 0, and remaining vertices are randomly assigned to levels $1, \ldots, h-1$. Each non-root vertex connects to a random parent in the previous level, ensuring the diameter does not exceed $D$.

This is done due to the fact that it is convenient for the design of the QPTAS which is used as an essential subroutine for both $O\br{\sqrt{\log n}}$ and the $O\br{\log\log n}$-approximation algorithm.

\subsubsection*{Extended Three-Field Notation for Experiments}

To systematically describe our experimental configurations, we extend the theoretical three-field notation $\alpha || \beta || \gamma$ to include specific tree generation methods and distribution types:

\textbf{Field $\alpha$ (Search Space):} In experiments, we specify the specific tree generation method using subscripts:
\begin{itemize}
    \item $T_R$ - Random trees
    \item $T_{\Delta}$ - Random bounded degree trees
    \item $T_D$ - Random bounded diameter trees
\end{itemize}

\textbf{Field $\beta$ (Query Characteristics):} 
We consider four cost scenarios:
\begin{itemize}
    \item $V$ - vertex queries with uniform unit costs ($c(v) = 1$ for all $v$)
    \item $V, c = \mathcal{U}$ - vertex queries with costs from uniform distribution $\mathcal{U}(0,1)$
    \item $V, c = \mathcal{B}$ - vertex queries with costs from binomial distribution $\text{Binomial}(n=10, p=0.5)$
    \item $V, c = \mathcal{E}$ - vertex queries with costs from exponential distribution $\mathcal{E}(\lambda=1)$
\end{itemize}

\subsubsection*{Performance Metrics}

Throughout the experimental analysis, we report the following metrics:

\begin{itemize}
    \item \textbf{Avg Time (s)} - Average CPU time in seconds over all instances of a given size.
    \item \textbf{Max Time (s)} - Maximum CPU time in seconds among all instances of a given size. 
    \item \textbf{Avg Depth} - Average depth of the decision tree produced by the algorithm, averaged over all instances of a given size.
    \item \textbf{Max Depth} - Maximum depth among all decision trees among all instances of a given size.
    \item \textbf{Avg Ratio} - Average approximation ratio over all instances of a given size.
    \item \textbf{Max Ratio} - Maximum approximation ratio among all instances of a given size.
\end{itemize}
