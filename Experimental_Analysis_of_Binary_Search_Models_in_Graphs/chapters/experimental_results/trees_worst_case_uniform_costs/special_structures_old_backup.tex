\textbf{Observations:}
\begin{itemize}
    \item Different tree structures exhibit varying search complexities
    \item Balanced structures generally perform better than path-like structures
    \item Path-like structures (caterpillar, broom) have higher search depths
    \item Star and spider graphs achieve near-optimal performance
    \item Algorithm adapts efficiently to different structural properties
\end{itemize}
