For bounded degree trees, the algorithm behaves similarly as for the random trees. The running time of the algorithm grows linearly, a little bit slower then for the random trees. The stabily is also preserved. Again, as expected, the average and worst case depths of the decision trees built grows logarithmically in $n$. This is easily explainable since it is not hard to see that $\rank\br{T} = \Omega\br{\log_{\Delta} n}$ because each query results in at least one response of size at least $\frac{n-1}{\Delta}$.
