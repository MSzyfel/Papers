\subsection{Random Trees}
\label{sec:random_trees}

This subsection presents results for uniformly random labeled trees generated using the standard random tree generation algorithm. In the worst-case uniform cost model, all queries have cost 1, and we measure the maximum depth (height) of the decision tree.

\subsubsection{Basic Random Trees}

\textbf{Description:} Uniformly random labeled trees on $n$ vertices.

\textbf{Results:}

\textbf{Observations:}
\begin{itemize}
    \item The average depth grows approximately as $\log_2 n$, consistent with theoretical bounds
    \item Runtime scales well with tree size
    \item Low variance indicates stable performance across different random instances
\end{itemize}
